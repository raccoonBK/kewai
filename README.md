# 课余（Kewai）· 校园行动 Agent

把校园通知与需求转化为**确定行动**的智能体。

> 未来智造智能体大赛 · 初赛项目（智慧生活与公共服务赛道）

## 这是什么

大学生每天被三类信息淹没：**校园通知**（讲座 / 比赛 / 材料提交）、**课余需求**（找资料 / 淘二手 / 找搭子）、**行政事务**（开证明 / 办事）。「课余」把这些散落在公众号、教务系统、微信群的信息，通过一个 Agent 转化为可执行的行动——

> 粘贴一条通知，或说一句"帮我找李教授高数真题"，Agent 解析意图、匹配资源、规划时间、落到日历，把报名 / 抢票 / 加入日历 / 办证明等动作推到你面前。

它不是"推荐活动"的信息流，也不是聊天机器人，而是一个以**行动闭环**为核心的 Agent：理解 → 规划 → 落日程 → 跟进。

## 核心功能

- **Agent 中枢**：自然语言 → 确定行动，已接 MiniMax 大模型（MiniMax-M3.1-Flash）
- **广场**：活动信息流 + 四大入口（资源市场 / 二手闲置 / 找搭子 / 证明办事）
- **日历**：周视图课表网格，课程灰底 + 活动彩色叠加，冲突排查
- **聚合中心**：资源 / 二手 / 搭子 / 证明办事四板块
- **引导与个人中心**：身份 / 年级 / 校区三步引导，档案授权、待办、同行小组、执行日志

## 技术栈

- **前端**：原生 HTML / CSS / JS（单文件，无框架，轻量易演示）
- **后端**：腾讯云 CloudBase（云函数 + 文档数据库 + HTTP 网关）
- **大模型**：MiniMax（MiniMax-M3.1-Flash）
- **运行环境**：Node.js 18（HTTP 函数 + scf_bootstrap）

## 本地运行

前端是纯静态文件，直接起一个静态服务器即可：

```bash
cd frontend && python3 -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777
```

单文件版：把 `frontend/` 三文件内联合并，或直接使用 `~/Downloads/课余-单文件前端.html`。

## 云函数部署

各云函数目录内含 `package.json` 与 `scf_bootstrap`（HTTP 函数范式，监听 9000 端口）。`MINIMAX_API_KEY` 在腾讯云控制台以环境变量配置，不写进代码。

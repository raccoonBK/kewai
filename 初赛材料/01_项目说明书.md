## 一、项目目标

大学生每天被三类信息淹没：**校园通知**（讲座、比赛、材料提交）、**课余需求**（找资料、淘二手、找搭子）、**行政事务**（开证明、办事）。这三类信息散落在公众号、教务系统、微信群，学生要么错过，要么被琐事反复打断。

「课余」的目标，是做一个**把通知与需求转化为确定行动**的校园智能体：

> 粘贴一条通知，或说一句"帮我找李教授高数真题"，Agent 自动解析意图、匹配资源、规划时间、落到日历，并把可执行的动作（报名 / 抢票提醒 / 加入日历 / 一键办证明）推到你面前。

它不是"推荐活动"的信息流，也不是"聊天机器人"，而是一个**以行动闭环为核心**的 Agent：理解 → 规划 → 落日程 → 跟进。

## 二、核心功能

### 1. Agent 中枢（自然语言 → 确定行动）
- 顶部导航：行动（✦）/ 搜索 / 日程三模式切换。
- 对话式交互：用户输入或粘贴通知，Agent 分四类落地：
  - **解析通知**：比赛/讲座/材料通知 → 行动清单 + 日程；
  - **匹配资料**：检索指定老师/科目的真题、笔记、PPT；
  - **搜罗二手**：校内淘教材、数码、生活用品；
  - **寻找搭子**：自习、球类、出游、竞赛组队。
- 每个推荐结果带**可执行动作按钮**：去报名（跳原链）、抢票提醒（已满时）、设提醒（闹钟）、加入日历。

### 2. 广场（活动信息流 + 四大入口）
- 「为你推荐 / 本周精选」双组卡片流，左图右文，含状态胶囊、时间地点。
- 四大金刚区：资源市场 / 二手闲置 / 找搭子 / 证明办事，一键直达。
- 卡片可点进**活动详情页**（底部滑出），支持加入日历、转发、报名。

### 3. 日历（课表 + 行动任务 + 活动叠加）
- 对接复旦 UIS 教务系统，**真实课表**自动同步进日历（灰底）。
- 活动/任务以彩色块叠加在课表空档上，直观看到"什么时间有空"。
- **冲突排查**：自动标记时间冲突并给出替代方案。

### 4. 聚合中心（四大板块）
- **资源市场**：闲鱼式多维筛选（学科/老师单选 + 类型/年份多选）。
- **二手闲置**：分类 + 成色 + 价格，双列网格。
- **找搭子**：场景筛选 + 缺人数 + 发起人卡片。
- **证明办事**：在读证明自助办理闭环（预填 → 提交 → 电子回执）。

### 5. 入口引导与个人中心
- 首次进入 3 步引导：身份 → 年级 → 校区（年级按身份动态，教职工自动跳过）。
- 个人中心：档案授权、闭环任务、同行小组、执行日志。

## 三、系统设计

### 3.1 整体架构

```
┌─────────────────────────────────────────────┐
│               前端（H5 / 小程序）              │
│  开屏 · 引导 · 广场 · 日历 · Agent · 聚合 · 我的 │
└──────────────────┬──────────────────────────┘
                   │ HTTP / 网关
┌──────────────────▼──────────────────────────┐
│            CloudBase 云函数（腾讯云）          │
│  ├ agent-chat     —— LLM 中转（MiniMax）       │
│  ├ uis-timetable  —— 复旦 UIS 课表抓取          │
│  └ activity-crawler —— 公众号活动抓取（定时）    │
└──────────────────┬──────────────────────────┘
                   │
      ┌────────────┼───────────────┐
      │            │               │
  MiniMax API   复旦 UIS      微信公众号
  (大模型)     (教务系统)    (搜狗→正文)
```

### 3.2 关键模块

**（1）Agent 决策中枢（agent-chat）**
- 前端把「用户输入 + 上下文（个人档案 + 活动/资源/二手/搭子数据）」POST 到云函数。
- 云函数拼「校园行动 Agent」system prompt，调用 MiniMax（MiniMax-M3.1-Flash，OpenAI 兼容）。
- 模型返回严格 JSON：`reply`（自然语言回复）+ 匹配到的条目 id。
- 前端按 id 渲染对应的活动/资源/二手/搭子卡片 + 动作按钮。
- 兜底：云函数不可用时回退到本地规则引擎，保证 demo 不白屏。

**（2）UIS 课表（uis-timetable）**
- 无需验证码、无需 2FA，纯后端模拟登录（与旦夕一致）。
- 链路：教务系统 4 级重定向拿 lck/entityId → RSA 加密密码 → POST 登录 → 拉 `print-data` 课表。
- 已通过前半段验证（认证方式 `userAndPwd, qr`，`second:false`），待端到端跑通。

**（3）公众号活动抓取（activity-crawler）**
- 43 个复旦公众号，搜狗按号精确搜索 → 解跳转 → 抓正文 → 抽取活动。
- 按需触发：用户问 Agent 时后台触发一次抓取（内部按自然日限流，一天一次），写入 CloudBase 数据库。

### 3.3 数据模型
- **activities**：活动（标题/类型/主办方/时间/地点/状态/原链）
- **resources**：学习资料（学科/老师/类型/年份/下载）
- **thrift**：二手（分类/成色/价格/校区）
- **buddies**：搭子（场景/缺人数/时间/地点/发起人）
- **courses**：课表（课程/周几/节次/地点/教师）
- **profile**：个人档案（身份/年级/校区，localStorage）

## 六、技术栈

- 前端：原生 HTML/CSS/JS（无框架，轻量、易演示）

- 大模型：MiniMax（MiniMax-M3.1-Flash）
- 运行环境：Node.js 18（HTTP 函数 + scf_bootstrap）
